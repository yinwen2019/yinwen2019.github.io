## Quality bar

The header and left profile retain their position and DOM nodes across all four routes. Ordinary links, direct URLs, browser history, keyboard focus, reduced motion, original figures, contact links and academic content remain usable. Desktop and 390px mobile have no horizontal document overflow. Route changes animate only the right content; network failure falls back to a normal page visit.
